**wtranslu 6.33**: sửa dứt điểm lỗi app tự tắt.

## Sửa lỗi
- **App tự tắt khi màn hình game có chữ sát mép dưới**, ví dụ HUD ở góc dưới bên phải (cấp độ, toạ độ, đồng hồ). Windows ghi lỗi `0xc0000005` trong `coreclr.dll`.
  - Nguyên nhân: tính năng giữ màu chữ và tô màu từng từ (mới từ 6.3) đọc điểm ảnh của vùng chữ. Với vùng chạm mép dưới ảnh, code đọc tràn ra ngoài vùng nhớ của ảnh, nên Windows dừng app ngay.
  - Cách sửa: giờ điểm ảnh được đọc từng hàng, đúng chiều rộng của vùng chữ.
  - Đã nhờ file `logs\rst_log.txt` (có từ 6.31) mà tìm ra lỗi này.
- Bản kiểm thử tự động có thêm chữ HUD ở góc dưới bên phải, và sẽ báo lỗi nếu RST tắt giữa chừng.
- Giữ các thay đổi an toàn của 6.31 và 6.32 cho phần chụp cửa sổ game.

## Tải về
- `wtranslu-setup-6.33.exe`: bộ cài, không cần quyền admin. Có thể cài đè lên bản cũ, cache và cấu hình vẫn được giữ.
- `RSTGameTranslation_v6.33.zip`: giải nén rồi chạy `rst.exe`.

> File chưa được ký số. Nếu Windows SmartScreen cảnh báo, bấm **More info → Run anyway**.
